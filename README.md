# Birki Zipper

> Public experimental source: see [PUBLICATION.md](PUBLICATION.md) for actual checks, known defects, restored modules and operational limits. Earlier audit decisions are historical.

## Описание

Небольшое настольное приложение на `tkinter` для пакетной архивации папок с бирками. Программа сканирует выбранный корневой каталог, показывает кандидатов на упаковку и помогает собрать итоговые ZIP-архивы с понятными именами.

## Возможности

- выбор корневой папки через графический интерфейс;
- фильтрация и отбор только готовых к архивации папок;
- массовое включение и исключение элементов из обработки;
- логирование операций и индикация прогресса;
- настройка перезаписи уже созданных архивов.

## Технологии

- Python
- `tkinter`
- стандартный модуль `zipfile`

## Запуск

```bash
python birki_zipper_tk.py
```

Перед запуском укажите собственную рабочую директорию с исходными папками, если путь по умолчанию не подходит.

## Статус

Готовый прикладной инструмент. При публикации внутренний сетевой путь подменяется на безопасный пример.
